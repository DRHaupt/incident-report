Field Map

Offline map for BC and Alberta · works with no signal once map data is installed

Find a place

  1. Type in the search box at the top: an address, Main St & 5th Ave, a facility, Hwy 97 km 120, or coordinates (decimal, DMS, MGRS, UTM).
  2. Tap a result to centre the map on it.
  3. Press and hold anywhere (right-click) → What's here? for the nearest address and every coordinate format.

Directions

  1. Tap a place → Directions here (or toolbar Directions).
  2. Choose Car, Emergency, Truck (enter height/weight/length) or Walking.
  3. Start for turn-by-turn with spoken prompts; it re-routes if you leave the route.
  4. Drawn road closures are avoided. Turn restrictions are obeyed.

Nearest help

  • Toolbar Nearest → AEDs, hospitals with ED, fire halls… sorted by drive time (AEDs also show walking time).
  • Tap a facility for details, source and last-verified date.

Copy a location for dispatch

  • Any details panel → Copy for dispatch; paste into CAD, e-mail or text.
  • Status bar: tap a coordinate to copy it.

Mark up the incident

  • Toolbar Draw: incident pin, staging, rendezvous, landing zone, cordon, perimeter, road closure, range rings, measure, hazmat zone (isolation + downwind).
  • More ▾ → Incidents & drawings to list, export (KML/GeoJSON/GPX) or import.
  • More ▾ → Export map as PNG/PDF or Print map.

Map files from an event

  • Drag a KML, KMZ, GPX, GeoJSON or CSV onto the map (or More ▾ → Import map file).
  • Layers → Event layers: show/hide, zoom to, fade the site plan, remove.

Field Toolkit

First aid, CPR, hazmat, location, timers, checklists, kit and radio · works offline

First Aid

  • Type what you see (not breathing, bleeding, bee sting) or pick a topic. Start here: scene safety comes first.
  • One step per screen: ← / → or the big buttons. Red banner = when to call 911.

CPR Helper

  • Pick Adult / Child / Infant → Start (or Space). Push to the beat (100–120/min); follow GIVE 2 BREATHS prompts; swap compressors every 2 min.
  • Starting it records "CPR started" in Timers.

Hazmat (ERG 2024)

  • Enter the 4-digit UN number on the keypad, a name, or "guide 128"; or tap a placard.
  • Green = Table 1 material: read isolation and protective-action distances (day/night, small/large spill).

Location

  • Lat/long, DMS, MGRS, UTM; tap a line to copy.
  • Read out on the radio spells the grid in radio figures.
  • Copy for dispatch; Save point for the incident or rendezvous (live distance and bearing).
  • Open in map shows it in Field Map.

Timers

  • Tap Tourniquet, CPR, Road closure, Crew on duty… Timers keep running when the window or app is closed.
  • An alert flashes and turns red until someone taps it.

Checklists · Kit

  • Run a checklist (vehicle pre-trip, medical kit, shift handover): OK / Fault / N/A per item, timed; a fault asks for a note. Copy report lists faults.
  • Kit: expiry or service dates for kits, meds, AED pads, O₂, extinguishers. Red = expired, amber = due soon; Checked today / Replaced….

Radio & Comms

  • Phonetic alphabet and live speller, procedure words, METHANE report.
  • Channel plan and call signs; time-stamped radio log (+ My location adds your grid); copy or save it.

Windows

  • Every tool opens its own window; + Window opens another of the same tool.
  • Launcher Arrange: side by side, stacked, grid. Pin on top keeps a window in front.

Incident Report Manager

Record, track and print incident reports · 96 forms · stored on this computer

Write a report

  1. File → New Report (Ctrl+N) → pick the category and form.
  2. Fill in the sections. Fields marked * are required to submit.
  3. Save (Ctrl+S) as you go – it stays a Draft.
  4. Submit Report when complete. Reviewers use Begin Review and Close Report; Reopen to change a closed report.

Add to a report

  • Attachments: photos, statements, documents (kept inside the database).
  • Create Follow-Up Report (Ctrl+Shift+N): investigation, corrective action, witness statement… with the incident details copied in.
  • Linked Reports shows the original and its follow-ups.

Find a report

  • Filter by status, date and category; Ctrl+F searches every field.
  • Click a column header to sort; the preview pane shows the selected report.

Print and export

  • File → Print (Ctrl+P) or Print Preview; blank forms can be printed to fill in by hand.
  • Export Report as HTML; Export List to CSV.

Look after the data

  • File → Back Up Database regularly (works while the app is open). Keep backups somewhere safe.
  • Tools → Options: organisation name, default reporter, report-number prefix, database location.
  • Closed reports are read-only; every change is in the audit history.
